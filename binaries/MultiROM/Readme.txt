MultiROM Binaries
=================

These are ROM sets for use with PET MultiROM adapters.

CHR..... Character Sets
DIAG.... Diagnostic Sets (KERNAL or EDIT)
EDIT.... Editor Sets
OPTROM.. OPTION ROMS for $9xxx and $Axxx

The BIN files have a matching TXT file which are the filenames for each slot.
There may also be a PDF for printing, or an XLSX file.
